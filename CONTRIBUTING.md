# Contributing

Contributions are welcome through GitHub issues and pull requests.

## Development workflow

1. Create a focused branch from `main`.
2. Install dependencies with `pnpm install --frozen-lockfile`.
3. Add or update tests with the implementation.
4. Run `pnpm run verify`.
5. Open a pull request describing behavior changes and configuration impact.

Do not include credentials, production endpoints, customer names, or real UNS
topic hierarchies in code, fixtures, logs, screenshots, or issue reports.
